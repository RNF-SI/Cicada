# 3. Notice Utilisateur

<p class="lead">À qui s'adresse cette notice ?</p>

Cette notice s'adresse à **toute personne possédant un compte CICADA**. Elle décrit les fonctions disponibles pour consulter l'information et gérer son compte. C'est le socle commun : **les administrateurs doivent aussi connaître cette partie**.

<p class="lead">Ce que vous pouvez faire en tant qu'utilisateur :</p>

<ul class="checklist" markdown>
- Vous connecter et gérer votre compte ;
- Consulter les sites et les plans de gestion auxquels vous avez accès (arborescence) ;
- Demander l'accès à un site, à un plan ou à un module ;
- Suivre vos demandes et recevoir des notifications ;
- Consulter le module d'exploration des données des plans de gestion ([§ 3.8](exploration.md)).
</ul>
