# 5.3. Gérer les sites

La page « Sites » liste les sites de votre organisme. Vous pouvez :

- **Créer ou modifier un site** : le bouton renvoie au module « Mes sites » ([§ 3.5](../utilisateur/notice/rejoindre-creer-site.md))
- **Lier des organismes au site** (dont l'organisme principal) ;
- **Associer des utilisateurs** (référents ou membres) (« Gérer les utilisateurs ») ;
- **Supprimer un site** (un avertissement signale les plans et utilisateurs rattachés).
