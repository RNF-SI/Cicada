# 5.2. Gérer les utilisateurs

La page « Utilisateurs » liste les comptes de votre organisme. Vous pouvez rechercher et filtrer (par rôle, par statut). Pour chaque utilisateur, vous pouvez :

- L'associer à un site (« Assigner un site ») ;
- Le retirer de votre organisme ;
- Demander sa promotion ou sa rétrogradation en tant qu'administrateur d'organisme (avec justification ; la demande est soumise aux super administrateurs).

L'activation et la désactivation des comptes sont réservées au super administrateur.
