# 6. Notice Administrateur d'une instance

<p class="lead">À qui s'adresse cette notice ?</p>

Cette notice s'adresse au super administrateur, qui pilote l'ensemble d'une instance de CICADA, sans limite de périmètre. Cette notice inclut tout ce qui précède ([Parties 3](../utilisateur/notice/index.md) [à 5](../admin-organisme/index.md)), appliqué à la totalité des organismes, sites et plans.

<p class="lead">Ce que vous pouvez faire en tant qu'administrateur d'une instance (en plus des droits utilisateurs, de référents de plan de gestion et d'administrateurs de sites) :</p>

<ul class="checklist" markdown>
- Superviser l'activité globale ;
- Gérer tous les utilisateurs, les rédacteurs généraux et les rédacteurs externes ;
- Gérer les modules, les journaux d'erreurs et du serveur, les demandes RGPD, les paramètres et les mises à jour.
</ul>
