# 6.5. Consulter les journaux d'erreurs et du serveur

La page Logs erreurs liste les incidents techniques (avec leur niveau de gravité). Vous pouvez filtrer, consulter le détail et acquitter une erreur (ou toutes).

La page Logs serveur permet de consulter les fichiers de journaux de l'application (général, erreurs, audit des actions), filtrés par niveau, et de les télécharger.
