# 4.11. Les documents du plan

Dans la vue d'ensemble, la section « Documents » permet de joindre des fichiers au plan (rapports, cartes…), en précisant leur type (document principal, annexe, carte, photographie, rapport d'étude, autre), de les télécharger et de les supprimer. La taille d'un fichier est limitée (20 Mo par défaut) : la limite, réglée par l'administrateur de l'instance, s'affiche dans la fenêtre « Ajouter un document », et un fichier plus lourd est refusé avant l'envoi.
