La zone DNS de ce domaine doit pointer vers l’adresse IP de ce serveur (enregistrements A ou AAAA). Selon votre hébergeur DNS, la propagation peut prendre de quelques minutes à plusieurs heures.

Pas de Traefik. Le frontend sera exposé sur le port ci-dessous. Vous devrez configurer un virtual host dédié sur votre Apache ou Nginx pour proxyfier le trafic vers ce port (et éventuellement /api vers le backend).

Indiquez ce port dans la configuration de votre reverse proxy (ex. ProxyPass vers http://127.0.0.1:8080).

Traefik sera utilisé sur les ports 80 et 443 (HTTPS avec Let's Encrypt). Aucune configuration Apache/Nginx nécessaire.

Exploration fédérée (optionnel)

CICADA peut publier la structure de ses plans validés vers un hub national, afin que la recherche porte sur les plans de toutes les structures participantes. Ne sortent jamais : le budget, les ressources humaines, les mesures et réalisations, les auteurs et les dates.

Cette case ne fait que préparer la configuration : rien n'est publié tant qu'un super administrateur n'a pas activé le partage dans « Administration > Paramètres ».

Les jetons sont délivrés par l'administrateur du hub. Vous pourrez aussi les renseigner plus tard dans /var/lib/cicada/.env.
⚠️ Définitif. Minuscules, sans espaces ni accents (ex. « rnf », « cen-aura »). Il apparaît dans la référence publique de chaque plan et ne peut plus être changé sans republier tout l'index.
Autorise cette instance à publier. Distinct du jeton de lecture : révoquer l'un ne doit pas emporter l'autre.
Si décoché, l'exploration reste locale : elle ne montre que les plans de cette instance, même si celle-ci publie.
