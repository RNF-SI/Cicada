# Signaler une vulnérabilité

Merci de **ne pas ouvrir d'issue publique** pour une faille de sécurité : le code
de CICADA est public, et une issue la rendrait exploitable sur toutes les
instances avant leur mise à jour.

Utilisez le signalement privé de GitHub : onglet **Security › Report a
vulnerability** de ce dépôt. Seuls les administrateurs du dépôt le voient.
Indiquez la version concernée, le chemin d'accès (URL, écran) et les étapes pour
reproduire.

Nous accusons réception sous une semaine. Le correctif est publié dans une
version de CICADA, déployée sur les instances par leur bouton « Mettre à jour »,
avant que le détail de la faille ne soit rendu public.
